Slate

An iPadOS-style home screen for Android tablets — folders, a dock, an App Library and a stack of useful widgets.

Download APKSource code

Built for Android tablets (tested on Xiaomi Pad 5, HyperOS) · Android 8.0 or newer · free · open source

What it does

  • Home pages and folders — drag apps around, drop them into folders, or let Smart organize sort them.
  • Dock — your favourites, then the apps you have open. Search and Recents buttons built in.
  • App Library — every app sorted into categories, plus search.
  • Widgets — clock, calendar, up next, to-do, notes, sticky notes, focus timer, habits, weather, world clock, countdown, screen time, photo frame and widgets from your apps. The stack snaps and moves on by itself.
  • Gestures on HyperOS — swipe up for Home, swipe up and pause for Recents, swipe in from a side for Back.

Install

  1. Download the latest Slate-v*.apk from Releases and open it (or adb install -r Slate-v*.apk).
  2. Open Slate and set it as your default Home app.
  3. For gestures: Settings → Accessibility → Slate gestures → on. On HyperOS also allow Autostart for Slate.
  4. HyperOS switches to 3-button navigation when another launcher is default. To get the gesture bar back: adb shell settings put global force_fsg_nav_bar 1.
  5. Optional: allow Usage access (Settings in Slate → System) for recent apps in the dock and the Screen time widget.

Privacy

Slate keeps everything on your tablet. It has no account and no analytics; the only thing that leaves the device is a city name or location for the weather widget, if you add one. Privacy policy · Terms of service
